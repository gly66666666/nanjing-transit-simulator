# 地铁线网实验室

在浏览器里规划地铁线路和站点，查看线网拓扑图，运行列车与客流仿真。

[在线试玩](https://gly66666666.github.io/nanjing-transit-simulator/)

## 内容

- **47 个单城版**按地理区域分组，包括北京、上海、南京、广州、香港和澳门。
- **7 个区域与城际版**包括长三角六城联动、长三角联动、大长三角、杭绍甬三城、杭绍甬城际、大湾区地铁总图和广东城际。

## 数据来源

部分线路的站序、站点坐标、轨道几何和颜色来自 [OpenStreetMap 贡献者](https://www.openstreetmap.org/copyright)，相关地图数据适用 [ODbL 1.0](https://opendatacommons.org/licenses/odbl/1-0/)。

苏州、哈尔滨等版本的站点坐标也参考 Wikidata 和中文维基百科。首页的线路和站点数量以各版本载入的默认线网为准。

## 使用

建议用电脑浏览器（Chrome / Edge）。下载仓库后直接双击 `index.html` 选择版本，无需安装依赖，也不需要联网。每个城市版本会在当前浏览器中独立保存规划，下次用同一个浏览器打开可继续。

首页可搜索城市或筛选版本，也可继续上次打开的地图。游戏页的「帮助」介绍各模式，「保存」可立即保存当前规划，窄屏可用「展开面板」查看控件。

首页和游戏页的「外观」默认跟随系统，也可固定为浅色或深色。在线版会在同一浏览器中记住选择并应用到各城市。规划时接入三个及以上站点，地图上的新线会以穿过各站的平缓曲线连接，仿真列车也会沿曲线运行。

## 目录结构

- `index.html`：城市索引页。
- `assets/`：公共引擎与样式。`sim-core-city.js` 和 `city.css` 由 46 个城市及城际版本共用。其他版本按各自的线网结构使用对应引擎和样式。
- `*模拟器.html` / `*总图.html`：只保留本版本的线路、站点、坐标、轨道和换乘数据（`LINE_DEFS`、`COORD`、`GEO`、`TRACK` 等），不再内嵌引擎代码。
- `_archive/`：本地保存的改造前快照（`backup-2026-11-22/`）和早期调试文件。

修改线路数据时只改对应 HTML 末尾的数据块；改交互或绘制逻辑时改 `assets/` 下的公共引擎。单独复制某个模拟器页面时，需要连同 `assets/` 一起复制，否则页面只有数据、没有引擎。

## 通用拓扑图算法

- 所有模拟器共用 `assets/octi-layout.js` 和 `assets/metro-chart.js`。布局根据共享站点划分连通分量，按规模分配网格空间，保留跨城线路全程，再按各分量的大致地理方位拼版。
- 换乘、分叉和终点作为锚点。带方向的 A* 搜索限制转弯内角至少为 90°，首末换乘站之间更偏向横竖走线。至多一个换乘站的单支非环线优先拉直。同线路重复交路复用轨段。
- 普通站沿所属线路依次放置，含普通站的轨段保留给停靠线路，减少视觉上的虚假停靠。区域全图按缩放级别逐步显示站点和站名，PNG 导出使用同一套走线和完整图例。
- `node --test tests/octi-layout.test.cjs` 检查全部城市和区域数据的站序、虚假停靠、重复轨段、转角，以及合成的跨城、支线和环线案例。

带方向的网格搜索参考 Bast、Brosi 和 Storandt 的八方向地铁图方法。[Metro Maps on Octilinear Grid Graphs](https://doi.org/10.1111/cgf.13986)
