# 地铁线网实验室

[在线试玩](https://gly66666666.github.io/nanjing-transit-simulator/)

在浏览器里规划地铁线路和站点，查看线网拓扑图，运行列车与客流仿真。

- **单城模拟**覆盖南京、常州、无锡、苏州、上海、南通和徐州。
- **长三角六城联动**可在同一张地图上查看南京、常州、无锡、苏州、上海和南通。

建议用电脑浏览器。下载仓库后可直接打开 `index.html` 选择版本，无需安装依赖。各版本会在当前浏览器中独立保存规划。

部分站点与轨道数据来自 [OpenStreetMap 贡献者](https://www.openstreetmap.org/copyright)，适用 [ODbL 1.0](https://opendatacommons.org/licenses/odbl/1-0/)。苏州单城版的站点坐标参考 Wikidata 和中文维基百科。
